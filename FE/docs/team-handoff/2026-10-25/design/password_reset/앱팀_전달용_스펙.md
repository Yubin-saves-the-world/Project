# 비밀번호 찾기 화면 스펙 (앱 팀 전달용)

화면 설계 이미지: `password_reset_board.png` (개별 화면 `1_initial.png` ~ `5_done.png`)

## 1. 한눈에

- 새 화면은 **1개**(비밀번호 찾기)와 **완료 화면 1개**입니다.
- 회원가입 화면(`signup_page.dart`)의 이메일 / 인증번호 구성과 같은 패턴이라서 `ReferencePage`, `ReferenceField`, `ReferenceButton`을 그대로 쓰면 됩니다.
- 로그인 화면의 `비밀번호 찾기` 링크(현재 ‘준비 중’ 안내)를 이 화면으로 연결합니다.

## 2. 레이아웃 (회원가입 화면과 동일한 규격)

| 요소 | 값 |
|---|---|
| 뒤로가기 | `backAsset: 'figma-655_768.svg'`, 누르면 로그인 화면 |
| 제목 | `비밀번호 찾기`, 30 / 39, Medium, 가운데, 상단 96 |
| 설명 | 14 / 21, 회색 `#808791`, 가운데, 2줄 |
| 입력 칸 | `ReferenceField(signup: true)` (테두리 `#E3E0D6`, 둥글기 14) |
| 칸 사이 간격 | 18 |
| 좌우 여백 | 24 |
| 버튼 | `ReferenceButton`, 높이 54, 파랑 `#4361EE` |
| 오류 글씨 | 12 / 18, 빨강 |

## 3. 칸 구성

| 칸 | 라벨 | 힌트 | 비고 |
|---|---|---|---|
| 이메일 | 이메일 | name@example.com | 오른쪽 `인증번호 받기`(발송 후 `재전송`), 라벨 오른쪽에 파란 타이머(5:00 → 0:00) |
| 인증번호 | 인증번호 | 인증번호를 입력하세요. | 숫자 키패드, 6자리 |
| 새 비밀번호 | 새 비밀번호 | 8자 이상 입력하세요. | 가림 입력, `autofillHints: newPassword` |

이메일 칸 아래 안내(발송 후): `메일이 보이지 않으면 스팸함도 확인해 주세요.` (12 / 18, 회색)

## 4. 동작

| 사용자 행동 | 서버 호출 | 성공 시 | 실패 시 |
|---|---|---|---|
| `인증번호 받기` | `POST /api/auth/password/reset-request` `{email}` | 타이머 시작 + 안내 창 `인증번호를 보냈어요` (아래 7번 새 디자인) | 아래 오류 표 |
| `비밀번호 변경` | ① `POST /api/auth/password/reset-verification` `{email, code}` → `reset_token`<br>② `PATCH /api/auth/password/reset` `{token, new_password}` | 완료 화면으로 이동 | 아래 오류 표 |
| `로그인하러 가기` | 없음 | 로그인 화면으로 이동 (이메일 칸은 채워 두면 친절) | |

- `reset-request`는 **가입 여부와 관계없이 항상 성공(204)** 합니다. 그래서 ‘가입되지 않은 이메일’이라는 문구는 만들 수 없고, 안내 창 문구도 같게 둡니다.
- ①이 성공하면 받은 `reset_token`을 ②에 바로 넣어 호출합니다. 사용자에게 보이는 단계는 `비밀번호 변경` 한 번입니다.
- 버튼은 이메일·인증번호(6자리)·새 비밀번호 규칙을 모두 만족할 때만 활성화합니다.

## 5. 오류 문구 (서버 `code` → 앱 표시)

| 서버 code | 표시 위치 | 문구 |
|---|---|---|
| `VALIDATION_FAILED` | 해당 칸 아래 | 서버 `fields[].reason` 그대로 |
| `EMAIL_CODE_INVALID` | 인증번호 칸 아래 | 인증번호가 일치하지 않아요. |
| `EMAIL_CODE_EXPIRED` | 인증번호 칸 아래 | 인증번호가 만료됐어요. 다시 받아 주세요. |
| `EMAIL_CODE_LOCKED` | 인증번호 칸 아래 | 입력 횟수를 초과했어요. 인증번호를 다시 받아 주세요. |
| `RESET_TOKEN_INVALID` | 버튼 위 | 비밀번호 재설정이 만료되었거나 올바르지 않아요. 처음부터 다시 진행해 주세요. |
| `EMAIL_SEND_FAILED` / 네트워크 오류 | 버튼 위 | 잠시 후 다시 시도해 주세요. |

- `재전송`은 60초에 한 번만 가능합니다. 60초가 지나기 전에 눌러도 서버는 `204`만 주고 새 메일은 보내지 않으니, 앱에서 60초 동안 버튼을 비활성으로 두는 것을 권장합니다.
- 인증번호는 5분, 5회 틀리면 잠깁니다.

## 6. 개발 모드(메일 발송 꺼짐)

서버를 `MAIL_ENABLED` 없이 켜면 메일이 가지 않고 **서버 콘솔에 인증번호가 찍힙니다.**
앱 개발 중에는 서버 콘솔에서 `[개발용] ... purpose=PASSWORD_RESET ... code=123456` 줄의 번호를 쓰면 됩니다.

## 7. 안내 창 (새 디자인)

기본 `AlertDialog` 대신 `Dialog`로 직접 만듭니다. 회원가입의 안내 창도 같은 위젯으로 바꾸면 통일됩니다.

| 요소 | 값 |
|---|---|
| 창 | 흰색, 둥글기 24, 좌우 여백 40, 안쪽 여백 30/24/24, 뒤 배경 `black 45%` |
| 아이콘 | 지름 64 원, 배경 `#EEF1FE`, 안에 파란 `#4361EE` 봉투 아이콘 |
| 제목 | `인증번호를 보냈어요`, 20 / 28, Medium, 가운데 |
| 설명 | `아래 주소로 6자리 번호를 보냈어요.` 14 / 21 회색, 아래에 받는 이메일을 15 / 22 Medium 검정으로 |
| 정보 박스 | 배경 `#F6F7FB`, 둥글기 12, 두 줄: `유효 시간 · 5분`, `입력 가능 횟수 · 5회` (왼쪽 회색, 오른쪽 Medium 검정) |
| 안내 | `메일이 보이지 않으면 스팸함도 확인해 주세요.` 12 / 18 회색 |
| 버튼 | `확인`, 높이 52, 둥글기 14, 파랑 `#4361EE` |

Future<void> showCodeSentDialog(BuildContext context, String email) => showDialog<void>(
  context: context,
  builder: (context) => Dialog(
    backgroundColor: Colors.white,
    insetPadding: const EdgeInsets.symmetric(horizontal: 40),
    shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(24)),
    child: Padding(
      padding: const EdgeInsets.fromLTRB(24, 30, 24, 24),
      child: Column(
        mainAxisSize: MainAxisSize.min,
        children: [
          Container(
            width: 64, height: 64,
            decoration: const BoxDecoration(shape: BoxShape.circle, color: Color(0xFFEEF1FE)),
            child: const Icon(Icons.mail_outline_rounded, color: ReferenceStyle.blue, size: 30),
          ),
          const SizedBox(height: 18),
          Text('인증번호를 보냈어요', style: ReferenceStyle.text(20, 28, weight: FontWeight.w500, spacing: -.3)),
          const SizedBox(height: 8),
          Text('아래 주소로 6자리 번호를 보냈어요.', style: ReferenceStyle.text(14, 21, color: ReferenceStyle.muted)),
          const SizedBox(height: 6),
          Text(email, textAlign: TextAlign.center, style: ReferenceStyle.text(15, 22, weight: FontWeight.w500)),
          const SizedBox(height: 18),
          Container(
            padding: const EdgeInsets.symmetric(horizontal: 16, vertical: 4),
            decoration: BoxDecoration(color: const Color(0xFFF6F7FB), borderRadius: BorderRadius.circular(12)),
            child: Column(children: [
              _infoRow('유효 시간', '5분'),
              const Divider(height: 1, color: Color(0xFFE6E8F0)),
              _infoRow('입력 가능 횟수', '5회'),
            ]),
          ),
          const SizedBox(height: 14),
          Text('메일이 보이지 않으면 스팸함도 확인해 주세요.', style: ReferenceStyle.text(12, 18, color: ReferenceStyle.muted)),
          const SizedBox(height: 20),
          SizedBox(
            width: double.infinity, height: 52,
            child: FilledButton(
              onPressed: () => Navigator.pop(context),
              style: FilledButton.styleFrom(
                backgroundColor: ReferenceStyle.blue,
                shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(14)),
              ),
              child: Text('확인', style: ReferenceStyle.text(15, 23, weight: FontWeight.w500, color: Colors.white)),
            ),
          ),
        ],
      ),
    ),
  ),
);

Widget _infoRow(String label, String value) => Padding(
  padding: const EdgeInsets.symmetric(vertical: 11),
  child: Row(
    mainAxisAlignment: MainAxisAlignment.spaceBetween,
    children: [
      Text(label, style: ReferenceStyle.text(13, 19, color: ReferenceStyle.muted)),
      Text(value, style: ReferenceStyle.text(13, 19, weight: FontWeight.w500)),
    ],
  ),
);
