## 서버가 준비되어야 완료되는 부분

- 개발용 인증번호는 여전히 123456이며 실제 메일을 발송하지 않습니다. 프론트 요청 제한은 화면 세션의 UX 보호이며 서버의 속도 제한·해시 검증을 대체하지 않습니다.
- 회원가입의 이메일 인증번호 발송·검증 API와 30분 유효·일회용 인증 토큰 계약이 필요합니다. 기존 가입 API 본문에 임의의 인증 토큰을 만들거나 보내지 않았습니다.
- 비밀번호 찾기의 서버 모드는 기존 F-13 메일 링크 계약입니다. 인증번호 확인으로 재설정 토큰을 받는 API가 정해지면 서버 모드도 연결해야 합니다. 로컬 완료 화면은 실제 비밀번호 변경 완료를 의미하지 않습니다.
- 실서버 계정의 중복 확인, 소셜 계정 제한, 5회 오류 잠금 및 재요청 제한, 새 비밀번호 저장은 서버에서 검증해야 합니다.
- 홈 운동 기록은 현재 기기 내 미리보기입니다. 세트별 실행·휴식 타이머, 실제 루틴 생성·분석·식단·미션·탈퇴 기능 등은 이번에 새로 구현한 범위가 아닙니다.
- HTTPS 배포 주소와 이메일 발송 설정·사진 원본 파기 정책은 백엔드 및 운영 설정이 필요합니다. 로컬 디버그 서버 연결은 유지했습니다.
