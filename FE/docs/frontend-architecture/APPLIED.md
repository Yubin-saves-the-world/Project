# 현재 프로젝트에 적용한 구조

적용일: 2026-10-06

설계 문서의 경로를 실제 프로젝트에 적용했다. MVP 기능에는 data/models와 presentation/pages·view_models·widgets 폴더를 준비했고 home/settings는 조합 화면이므로 데이터 계층을 만들지 않았다. workout에는 로컬 초안·동기화·타이머 알림 위치를 추가했다. 2차/확장 기능은 최상위 폴더와 역할 설명만 예약했다.

실제로 연결한 Dart 파일은 앱 진입·테마·라우터·탭·기본 페이지와 공통 위젯이다. 데이터 모델·API·Repository를 빈 Dart 파일로 전부 만들지는 않았다. 해당 기능을 구현할 때 구조 문서의 파일명으로 추가한다.

초기 경로는 기본 Flutter 라우터의 `/`(홈), `/analysis`, `/workouts`다. 앞선 내부 경로 제안의 `/home` 대신 홈을 `/`로 연결했다. 탭 전환은 IndexedStack으로 각 화면 상태를 유지한다. 인증 redirect와 실제 기능 데이터는 아직 없다.

설계에 추천한 외부 패키지는 설치하지 않았다. 이 변경은 구조 적용 범위이며 API·인증·상태 관리 도입은 다음 작업이다. Figma의 주 CTA #7BAF1E, 배경 #FAFAF8, 주요 여백24를 공통 테마에 반영했다. 등록된 폰트 자산이 없어 현재는 기본 폰트다.

기존 화면과 맞지 않던 카운터 테스트를 MVP 탭 전환 테스트로 교체했다. 자세한 실행 명령은 루트 README를 따른다.

검증 결과: Dart 포맷 적용, `flutter analyze` 오류 없음, `flutter test` 탭 전환 테스트 1개 통과. 상대 import와 문서 링크도 확인했다. 기기 실행·완성 디자인·백엔드 연동을 검증한 결과는 아니다.

후속 작업으로 [가입 3페이지](ONBOARDING.md)를 구현했다. 현재 앱 시작은 `/signup`이며 저장된 로컬 설정이 완료되면 홈을 표시한다. 위 기본 화면·의존성 설명은 최초 구조 적용 시점의 기록이다.
