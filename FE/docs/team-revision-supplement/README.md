# Project Vitality 팀장 수정본 보완안 v1.2

작성일: 2026-10-06 · 상태: 팀 검토용 제안

## 범위 변화

MVP 11개 기능, 2차 10개 기능, 확장 4개 기능을 유지한다. 원문 95개 엔드포인트에 확장용 `DELETE /api/users/me/device-token` 1개를 추가하여 보완안 기준 96개다. 기존 신고 조회·처리 관리자 API 2개는 확장에서 2차로 이동한다. 따라서 MVP 35개, 2차 36개, 확장 25개다. 단계 이동은 전체 수를 늘리지 않는다.

서버의 DELETE 탈퇴 응답 204→202, 동의 완료 플래그 의미, 날짜 상태, 운동 충돌 처리, 추가 오류 코드는 FE·BE가 함께 적용해야 한다. API 문서만 바꾸고 기존 목 데이터·화면 분기·DB 제약을 그대로 두면 동작이 달라진다.

## 확인 범위

공유된 기능 요구사항과 펼쳐진 95개 API의 내용에 근거해 작성했다. 수정 ERD·실제 코드·별도 ADR 원문은 제공되지 않았다. 따라서 데이터 항목은 마이그레이션 완료 사실이 아니라 반영 제안이다. 판정 산식의 검증 자료, 운동 처방 데이터, 제휴 계약·쿠폰 공급 방식은 별도 산출물이 필요하며 문서 작성만으로 검증됐다고 간주하지 않는다.
