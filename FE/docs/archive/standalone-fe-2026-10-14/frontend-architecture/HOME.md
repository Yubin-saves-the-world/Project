# 홈 구현 기준

Figma `05 홈`의 최신 노드는 `665:360`이다. MCP로 전체 디자인 코드와 참고 이미지를 읽고 Flutter 공통 테마로 구현했다. 피그마 파일은 수정하지 않았다. 원본 참고 이미지는 `docs/figma-reference/home/home.png`, 구현 미리보기는 `docs/frontend-architecture/previews/home.png`에 보관한다.

## 화면과 동작

- 실제 한국 시간 날짜와 저장된 닉네임을 사용한다.
- 월~일 요일을 선택하면 해당 날짜의 루틴 예시와 기록을 확인한다.
- 오늘의 루틴 카드·식단/자세 교정 카드·미션 카드는 Figma의 순서·여백·둥근 테두리·파란색을 따른다. 글꼴은 기존 로그인/가입과 같은 CapstoneUI를 재사용했다.
- 영문 날짜·오늘의 루틴·분 단위·인공지능 코치 표기를 한국어로 바꿨다. 달력의 기본 문구도 한국어가 되도록 Flutter 한국어 localization을 적용했다. `kg`는 무게 단위 표기다.
- 알림·홈은 사용자가 제공한 `bell.svg`와 `home.svg`를 사용하고 나머지는 Flutter 기본 아이콘을 사용한다. 알림은 17.5×20, 홈은 20×20로 비율을 유지해 약 2px의 선 굵기로 주변 아이콘에 맞췄다.
- 하단은 홈·분석·기록·인공지능 코치·커뮤니티 5개 탭이다. 분석/기록은 기존 준비 화면을 유지하며 코치/커뮤니티도 서비스 연결 전 안내 화면이다.
- 홈의 계정 메뉴에서 기존 로그아웃을 계속 사용할 수 있다. 알림 버튼은 알림 준비 안내를 연다.
- 문서의 F-10에 따라 기록 달력과 선택 날짜의 총 세트·볼륨을 추가했다. 스크롤해서 볼 수 있다.

## 개발용 데이터 경계

현재 서버와 AI 분석은 연결되지 않았다. 오늘의 루틴은 ‘예시’로 표시한 하체 4종목이다. 날짜별 계획도 화면 테스트용이다. 개인에게 실제로 처방한 루틴이 아니다.

홈의 운동 시작은 예시 루틴 전체 목록을 연다. 종목을 선택하면 기기 내 미리보기 기록이 시작되고, 실제 입력한 무게·횟수·세트 수로 종목 완료를 테스트할 수 있다. 기록은 계정 이메일별로 구분된 SharedPreferences에 저장하며, 이어하기와 볼륨·달력·완료 수·연속일을 계산한다. 미리보기 기록은 실제 `workout_logs`/`workout_sets` 서버 데이터와 별개다. 세트별 기록·타이머를 포함하는 전체 운동 실행 화면(F-09)은 이 홈 미리보기로 완성되었다고 보지 않는다.

식단 칼로리·자세 이상 판정·실제 할인권은 임의로 생성하지 않는다. 이 카드들은 준비 상태로 표시한다. 이번 주 미션은 미리보기 목표이며 보상을 발급하지 않는다.

## 체형분석에서 홈으로 이동

`OnboardingAnalysisPage._finish()`는 이제 `model.finish(prepareAnalysis: false)`를 호출한다. 사진·글·목표 사진이 없어도 가입/신체정보가 저장된 상태에서 홈으로 이동한다. 분석 입력을 보관할 수 있지만 실제 분석을 요청하거나 `analysisPrepared=true`로 표시하지 않는다. 저장 실패가 발생한 경우에는 입력을 유지하고 재시도 안내를 표시한다.

## 파일 역할

- `home_page.dart`: 홈 카드, 요일, 달력/기록 창, 운동 미리보기 입력창.
- `home_view_model.dart`: 예시 루틴 일정, 날짜 선택, 기록 집계, 진행 중 운동, 저장 실패 처리.
- `home_preview_repository.dart`: 기기 내 미리보기 운동 기록 형식과 저장/복원.
- `app_bottom_nav.dart`, `main_shell.dart`: 5개 탭과 탭별 화면.

서버 연결 시에는 주간/오늘 루틴 API 응답을 받을 실제 루틴 모델과 저장소를 구현하고, 정적인 예시 루틴을 대체해야 한다. 미리보기 저장소를 서버 저장소로 이름만 바꾸는 것으로 API 연동이 끝나지는 않는다.

필요한 MVP API: `GET /api/routines/weekly`, `GET /api/routines/today`, `GET /api/workout-logs`, 운동 기록 상세와 운동 실행 API. 연속 운동·식단·교정은 2차, 미션/할인권·알림은 확장 기능이다.

## 확인

홈의 393×852 화면 비교, 320×640·1.5배 글꼴, 예시 운동 시작/중복 시작/완료/기록 복원/볼륨/연속일/저장 실패, 탭 이동과 분석 입력 없이 홈 이동을 테스트한다. 기존 로그인·회원가입·신체정보 테스트도 유지한다.

홈 상단의 요일·월·일 날짜 문구는 제거했다. 주간 선택기는 회색 개별 배경과 점을 없애고 하나의 흰색 테두리 영역에 요일·일자를 배치했다. 선택 날짜만 파란색으로 강조하며 날짜 선택 동작은 유지한다.

## 기능 보완과 홈 배치 개선

- 횟수·세트 입력은 검증과 저장에 동일한 정수 파서를 사용한다. `3.0`이나 지수 표기는 안내 메시지로 거부하고 예외가 발생하지 않는다. 무게 0~500kg, 횟수 1~100, 세트 수 1~20 범위를 UI·ViewModel·저장 데이터 복원에서 검사한다.
- 기록 조회/복원 실패 시 쓰기를 막고 ‘다시 불러오기’를 제공한다. 잘못된 기록을 자동으로 삭제하거나 빈 목록으로 기존 저장값을 덮어쓰지 않는다.
- 다른 종목이 진행 중이면 기존 운동 이어하기 또는 취소하고 새 운동 시작을 선택한다. 운동 입력창에서 확인 후 취소할 수도 있다. 취소는 진행 중 기록만 제거하며 완료 기록은 유지한다.
- 6시간을 넘긴 진행 중 운동은 자동 중단 상태로 보존하며 완료·볼륨·미션·연속일 집계에서 제외한다. 자동 중단 저장에 실패하면 추가 쓰기를 막고 복원 재시도를 요구한다.
- 주간 예시 계획은 월요일 기준 고정 요일로 계산한다. 하루가 바뀌어도 같은 주의 계획이 달라지지 않는다. 앱 복귀/분 단위 확인으로 한국 시간의 오늘과 이번 주를 갱신한다.
- 과거·미래 날짜의 루틴은 조회 전용이고, 새 운동은 오늘만 시작한다. 자정을 넘어 완료한 진행 중 운동은 시작 날짜에 기록하고 해당 기록 날짜를 보여준다.
- 전체 4종목 보기, 종목별 완료 표시, 전체 완료 시 기록 보기 상태를 제공한다. 완료한 종목을 다시 시작해 루틴 진행률을 중복 올리지 않는다.
- 상단 문구는 오늘의 운동일/휴식일에 맞춘다. ‘오늘로’ 버튼으로 현재 날짜에 복귀한다.
- 운동 기록 카드를 준비 중 카드들보다 먼저 배치했다. 식단·교정·미션의 준비 중 문구와 아이콘은 변경하지 않았다.
