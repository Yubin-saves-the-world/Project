# AI 전용 홈·상세 분석과 독립 평가

## 화면 사용

AI 서버의 `/`는 분석 전용 홈이고 `/analysis`는 사진 측정·상완 검수 상세 화면입니다. 기존 Flutter·FE·BE 코드는 변경하지 않습니다. `bash AI/run.sh`로 실행하며 현재 개발 컴퓨터의 준비된 서버는 http://127.0.0.1:8005/ 입니다.

1. 홈의 **새 사진 분석하기**에서 정면 전신 JPG/PNG를 선택합니다.
2. 측면 사진이 있으면 함께 넣고 **사진 분석하기**를 누릅니다.
3. 측정값·뜻·한계·미측정 이유와 관절 연결 이미지를 확인합니다.
4. 상완 크롭에서 실제 피부와 위치를 확인한 경우에만 분류를 실행합니다. 가림이 있으면 확인 체크를 하지 않습니다.
5. **이 브라우저에 수치 기록**을 누르면 숫자만 선택 저장합니다.
6. 홈의 기록에서 상세 보기·선택 삭제·두 기록 비교를 사용합니다.

브라우저 기록에는 사진·크롭·특징 벡터·검수 토큰·분류 등급·원본 파일명을 저장하지 않습니다. 최대 30개이며 오래된 항목부터 제거합니다. 같은 브라우저·기기·서버 주소에서만 보이고 다른 포트에서는 별개입니다. 수치도 개인 정보가 될 수 있으므로 공유 기기에서는 삭제하세요. 비공개 모드나 저장 차단·공간 부족 시 기록 저장이 실패할 수 있습니다. 서버 계정 기반 기록 서비스는 아닙니다.

같은 사람·같은 촬영 조건의 기록을 비교해야 합니다. 서로 다른 측정 버전은 비교하지 않습니다. 변화량을 개선·악화로 판정하지 않습니다.

## 데이터 준비 상태

`AI_REVIEWED_DATASET=/절대경로/AI/.runtime/검수묶음`을 설정해 서버를 시작하면 홈에 실제 라벨 수·제외·대기·등급별 인물 그룹 수를 표시합니다. 미설정 시 사진 분석은 유지하고 자료 미연결을 안내합니다. `/v1/data-readiness`는 설정한 자료의 집계만 반환하며 사용자 요청으로 임의 파일 경로를 받지 않습니다.

새 자료를 충분한 표본이라고 보장하지 않습니다. 인물 그룹 수는 라벨의 ID 기준이며 동일인 확인은 사람이 해야 합니다. 기존 자료로 fit-only 학습을 했으면 그 자료를 독립 시험 자료로 재사용할 수 없습니다.

## 윤곽 라벨 기준 v1

분류 대상은 **촬영된 상완 피부에서 보이는 윤곽의 가시성**입니다. 근육량·체지방·근력·건강이나 정상 체형의 정답이 아닙니다. 이 기준은 프로젝트의 작업 정의이며 임상 기준이 아닙니다.

| 라벨 | 작업 정의 |
| --- | --- |
| weak | 위치와 피부가 선명하게 확인되지만 영역 내부의 분리된 윤곽은 뚜렷하지 않음 |
| medium | 일부 윤곽을 확인할 수 있으나 영역 전체에서 명확한 분리가 일관되지는 않음 |
| clear | 촬영된 상완에서 구분되는 윤곽이 비교적 명확하게 보임 |
| exclude | 의복·가림·흐림·작은 크기·잘못된 부위·사용 부적합 등으로 등급을 판단하기 어려움 |

weak는 흐림·어두움·가림의 대체 라벨이 아닙니다. 가능하면 2명이 독립적으로 검수하고 의견 차이를 별도로 확인합니다. 기준 예시를 함께 합의하되 평가 결과를 보고 정답을 바꾸지 않습니다. 포즈·힘주기·조명·각도 편향을 기록하고 성능 한계로 보고합니다. 사진 권리·동의·출처·이용 범위도 별도 확인해야 합니다.

## 독립 시험 절차

1. 학습 원본과 모든 증강·크롭을 기준으로 사용 이력을 고정합니다.
2. 새로운 사람의 별도 사진을 확보하고 동일인 여부를 사람이 확인합니다. ID 접두사만 바꾸는 것은 독립성이 아닙니다.
3. 원본과 최종 크롭을 확인한 뒤 등급을 사람이 저장합니다. 같은 사진의 양팔은 같은 인물 ID를 사용합니다.
4. 시험 자료를 모델 학습·설정 선택에 사용하지 않습니다. 최소한 모델이 다루는 모든 등급이 있어야 합니다.
5. 다음 명령은 **실제로 독립성 확인을 완료한 경우에만** 확인 옵션과 함께 사용합니다.

```bash
AI/.venv/bin/python AI/scripts/evaluate_independent_contours.py \
  --model AI/.runtime/models/contour-home-v1/model.json \
  --training-dataset AI/.runtime/merged_with_kaggle_v2 \
  --test-dataset AI/.runtime/independent_human_reviewed \
  --output AI/.runtime/independent-evaluation.json \
  --confirm-independent-identities
```

모델에 학습 자료·라벨의 해시가 기록돼 있어야 하며 지정한 학습 자료와 일치하는지 확인합니다. 원본 사진·특징·인물 ID의 교집합을 거절하고, 미검수나 등급 누락도 차단합니다. 원본을 재압축·자르기·변형한 근접 중복과 서로 다르게 적힌 동일인 ID는 자동으로 완전히 찾을 수 없습니다.

보고서는 등급별 표본 수, 후보 정확도·Macro-F1·혼동행렬, 판정 가능한 비율과 그 안에서의 정확도를 구분합니다. 후보 점수는 정확도나 건강 점수가 아닙니다. 작은 한 묶음의 평가를 일반화된 실사용 정확도로 주장하지 않습니다. 모델과 기존 보고서는 덮어쓰지 않습니다.
