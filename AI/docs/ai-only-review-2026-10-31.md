# AI 전용 코드 리뷰 및 변경 범위 정정

## 확정 범위

사용자 지시에 따라 변경 경로는 `AI/` 하위뿐입니다. FE, BE, 루트 docs, 루트 .gitignore, 공통 실행 설정은 원본과 동일합니다. 이후 변경도 문서·테스트·설정을 포함해 AI 안에서만 수행합니다. AI/AGENTS.md에 이 조건을 기록했습니다.

## 기존 통합 변경 철회

이전 PR #4·#5·#6은 AI 외 변경이 포함되어 병합하지 않고 닫았습니다. main에는 해당 변경이 적용되지 않았습니다. 별도 로컬 작업본에서 변경했던 비AI 파일과 추가 소스도 원본으로 복구했으며 사용자 사진·DB는 보존했습니다. 기존 원격 브랜치 삭제는 자동 승인 검토에서 명시적 승인 부족으로 거절되어, 기록은 남기되 닫힌 PR로 철회 상태를 유지합니다. 새 AI 전용 PR만 검토 대상입니다.

## AI 구현과 수정

- MediaPipe의 각도·거리 계산에 픽셀 좌표를 사용합니다.
- 동결된 공식 DINOv3로 상완 특징을 추출합니다. 근육 분류기는 학습하지 않았습니다.
- 누락·비유한 비율과 관절 신뢰도를 방어하고 이미지 형식·크기·해상도를 제한합니다.
- 새 `/v1/analyze`는 snake_case 응답을 반환합니다.
- 기존 `/analyze/body`는 기존 MediaPipe 파이프라인과 camelCase 응답·text 입력을 유지합니다. 업로드는 1~3장으로 제한하며 임시 파일은 응답 후 삭제합니다.
- 두 경로의 동시 요청을 제한하고 잘못된 입력·과부하·추론 실패를 구분합니다.
- Git 제외 규칙은 AI/.gitignore에만 둡니다.

## 검증

- Python unittest 12개 통과: 관절 기하·누락 값, API 응답, 기존 형식/text, 잘못된 사진·큰 파일·장수 제한, 동시 요청 거절, 실패 후 슬롯 반환 및 임시 파일 정리.
- 가짜 엔진 API 테스트와 별도로, 승인된 로컬 공식 모델 및 test1.jpg로 `/v1/analyze` 실제 DINOv3·MediaPipe 실행을 확인했습니다. 상완 두 영역과 CLS 384차원을 확인했습니다.
- `/analyze/body`도 실제 MediaPipe 파이프라인과 camelCase 응답을 확인했습니다. 기존 휴리스틱의 정확성이나 진단 타당성을 검증했다는 뜻은 아닙니다.
- 위 검증 중 프론트·백엔드 서버를 실행하지 않았고 DB를 사용하지 않았습니다. 개인 사진·토큰·가중치는 커밋하지 않습니다.
- Git 트리 비교에서 FE·BE·루트 docs·루트 .gitignore의 객체 해시가 main과 같습니다. 모든 새 커밋의 변경 파일이 AI/ 하위임을 검사합니다.

## 남은 제한

근육 등급 학습, 다중 인물·정면·의복 검사, 측면 목 분석, 목표 비교·운동 추천은 미구현입니다. 새 API는 JWT·DB·분석 이력·사용자별 할당량을 담당하지 않습니다. 호출 연동은 담당자에게 AI/docs/dinov3-api.md로 전달합니다. 임베딩 추출을 근육 발달 판정으로 사용하지 않습니다.
