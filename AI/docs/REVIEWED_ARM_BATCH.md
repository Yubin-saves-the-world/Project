# 새 사진의 원본·상완 검수 묶음

기존 격리 자료와 그 파생 모델은 재사용하지 않습니다. 새 검색 후보 24장을 원본 전체로 직접 확인하고 가림·해상도·다중 인물·구도 등을 점검했습니다. 처음 선별한 5장 중 추가로 저해상도 및 검출/가시성 문제를 제외해 사진 3장, 상완 4영역을 현재 라벨링 화면에 제공합니다. 원본과 최종 크롭을 각각 확인했습니다. '모든 용도에서 권리 문제가 없음' 또는 연령·신원 확인을 뜻하지 않습니다. 출처와 재사용 라이선스는 별도 source-licenses.json에 기록합니다.

## 분리된 준비 경로

`scripts/prepare_reviewed_arm_photos.py`는 명시적으로 육안 검수 승인한 manifest와 원본 SHA256이 일치할 때만 작동합니다. 격리 경로·미검수 자료·변경된 원본은 거절합니다. 기존 데이터셋은 덮어쓰지 않습니다.

상완 분류용 데이터 준비는 전신 기울기/비율 측정과 분리합니다. 자동 경로는 어깨·팔꿈치 신뢰도 0.7, 정상 이미지 범위, 원본 상완 길이와 크롭 크기를 확인하고 짧은 변 128px 미만은 제외합니다. 얼굴·발목 누락만을 이유로 상완 자료를 거절하지 않습니다. 기존 /v1/analyze의 전신 검사는 변경하지 않았습니다.

1장의 흑백 원본은 자동 포즈 검출 실패로 원본을 직접 확인해 지정한 수동 영역을 사용했습니다. `crop_method=assistant_manual_roi`, visible_upper_arm으로 기록하며 해부학적 좌우를 추측해 표시하지 않습니다. 수동 영역도 별도로 육안 확인했습니다. 신뢰도 있는 관절 검출에 성공했다고 표현하지 않습니다. 흑백·자세·수동/자동 영역 차이는 후속 모델 평가의 제한입니다.

특징은 같은 공식 DINOv3 리비전의 768차원 형식입니다. 윤곽 등급과 reviewed=true 라벨은 생성하지 않습니다. 기존 철회한 실험 모델은 사용하지 않습니다.

## 라벨링

현재 AI/.runtime/reviewed_arm_batch_v2를 127.0.0.1:8002에 연결했습니다. 원본 3장의 상완 4영역을 검수합니다. 임시 인물 ID는 safev2_person01~03입니다. 각 원본의 좌우 상완은 같은 임시 ID를 제안하며 최종 확인은 사람이 합니다. 이는 사진 간 자동 인물 식별 기능이 아닙니다. 같은 사람의 다른 사진을 추가할 때는 사람이 ID를 맞춰야 합니다.

새 항목은 초기 train 값을 사용합니다. 지금의 작은 묶음만으로 학습·평가가 완성되는 것은 아니며 학습 전 전체 자료의 인물 단위 분할을 별도로 설계해야 합니다. 학습용/평가용 이름을 바꿔서 부족한 등급을 만들어내지 않습니다.

사용자는 원본과 크롭, 사전검수 이유를 보고 weak/medium/clear/exclude를 직접 저장합니다. 원본 자료와 이전 라벨은 보존했습니다. 이미지·대기 자료·manifest·특징은 AI/.runtime에만 보관하고 공개 Git에는 올리지 않습니다. 미선정 후보를 보여주는 별도 서버는 종료했습니다.
