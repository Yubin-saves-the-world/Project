# 상완 윤곽 라벨링·학습·평가

## 지금 준비된 범위

사람이 검수한 실제 라벨이 없어 배포용 분류기는 아직 학습하지 않았습니다. 테스트용 합성 특징으로 학습·JSON 저장·예측 연결을 검증한 것과 실제 근육 분류 성능을 구분합니다. 임의의 자동 라벨이나 기존 체형 규칙을 정답으로 사용하지 않습니다.

분류 대상은 사진에서 보이는 **상완 윤곽의 가시성**입니다. 근육량, 근력, 건강·정상 여부, 의학적 등급을 예측하지 않습니다. 실제 사람의 근육 발달 정도를 검증한 모델이라는 의미로 사용하지 않습니다.

## 1. AI 서버 시작

프로젝트의 AI 폴더에서 `bash run.sh`를 실행합니다. 기존 승인 계정과 Python 3.12 설정을 사용합니다. 다음 명령들도 AI 폴더에서 실행합니다.

## 2. 사진 준비와 로컬 검수 화면

다른 터미널에서 실행합니다.

```sh
.venv/bin/python scripts/label_contours.py --images /절대/사진/폴더
```

사진은 로컬 AI 서버로만 보냅니다. 정면 전신 사진에서 추정한 좌우 상완을 자르고 DINOv3 특징을 준비합니다. 신뢰도가 낮은 영역은 라벨링 대상에서 제외합니다. 처음에는 AI/.runtime/contour_dataset에 이미지·특징만 준비하며 라벨은 비어 있습니다. 그다음 `http://127.0.0.1:8002`에서 검수합니다.

- 같은 사람은 모든 사진과 좌우 상완에 같은 인물 ID를 입력합니다. 예: person01. 사진 파일명마다 다른 인물 ID를 만들지 않습니다.
- 인물 ID는 영문·숫자·밑줄·하이픈을 사용합니다. 실제 이름을 입력할 필요가 없습니다.
- 같은 인물은 train/val/test 중 한 구분에만 넣습니다. 인물 ID는 사람이 입력하며 서버가 동일 인물을 자동 인식하는 것은 아닙니다.
- 라벨을 선택하고 ‘저장하고 다음’을 눌러야 검수 완료로 저장됩니다. ‘저장 없이 다음’은 라벨을 만들지 않습니다.
- 원본 사진과 잘린 영역을 함께 확인합니다. 같은 사진의 좌우 상완 인물 ID가 다르거나 같은 사람이 서로 다른 구분에 들어가면 저장을 거절합니다.

| 라벨 | 사진상 기준 |
| --- | --- |
| weak / 약함 | 노출된 상완에서 경계·음영이 거의 구분되지 않음 |
| medium / 중간 | 일부 윤곽이 구분됨 |
| clear / 뚜렷함 | 상완의 경계·음영이 명확하게 구분됨 |
| exclude / 제외 | 옷·가림·흐림·잘못 잘린 영역 등으로 판단할 수 없음. 이유 입력 필수 |

**옷으로 가려지거나 흐린 사진을 weak로 입력하지 않습니다.** 라벨 기준은 초기 개발용이며 평가자 간 합의·독립 검수로 더 구체화해야 합니다.

다시 열 때는 원본을 재분석하지 않습니다.

```sh
.venv/bin/python scripts/label_contours.py
```

저장 경로를 바꾸려면 --dataset을 사용하되 AI/.runtime 아래여야 합니다. 준비된 데이터셋은 덮어쓰지 않습니다. 다른 사진 모음은 별도 --dataset을 지정합니다.

## 3. 학습 사전 검사와 학습

```sh
.venv/bin/python scripts/train_contours.py --validate-only
.venv/bin/python scripts/train_contours.py
```

사전 검사 조건은 다음과 같습니다.

- 사람이 저장한 reviewed=true인 라벨만 사용합니다. 제외한 영역은 학습하지 않습니다.
- 최소 2종류의 라벨이 필요합니다. 학습할 모든 클래스가 train/val/test에 존재해야 합니다.
- 각 클래스에 대해 train은 서로 다른 인물 ID 2개 이상, val과 test는 각 1개 이상이 필요합니다. 이 수량은 도구의 최소 조건이며 성능을 보장하는 표본 수가 아닙니다.
- 같은 인물·원본 사진·완전히 같은 특징이 구분을 넘나들면 거절합니다. 원본의 좌우 상완도 분리하지 않습니다.
- 특징 형식·모델 리비전·768차원 유한 벡터를 검사합니다.

기본 모델은 동결 DINOv3의 CLS 384 + 평균 패치 384를 연결하고 L2 정규화한 선형 LogisticRegression입니다. train만 학습하고 val Macro-F1으로 C를 선택합니다. test는 학습·C 선택에 쓰지 않으며 최종 평가에만 사용합니다. 출력은 model.json과 training-report.json입니다. 피클 모델을 로드하지 않습니다.

보고서는 클래스별 표본·인물 ID 수, accuracy, Macro-F1, 혼동행렬, 판정 가능한 비율과 판정한 표본의 정확도를 포함합니다. 0.6인 기본 판정 보류 임계값은 초기 실험 설정이며 검증된 신뢰도나 임상 기준이 아닙니다. --threshold로 변경할 때도 test를 보고 최적화하지 않습니다.

## 4. 학습한 모델을 AI 서버에 연결

검수와 학습이 실제로 완료된 뒤에만 실행합니다.

```sh
AI_CONTOUR_MODEL="$PWD/.runtime/contour_dataset/model.json" bash run.sh
```

서버는 형식·특징 버전·DINOv3 리비전을 검사한 JSON 분류기만 읽습니다. 상완 결과의 contour에 predicted/abstained, label, model_score, probabilities, experimental을 추가합니다. 모델 점수는 보정된 실사용 정확도가 아닙니다. 임계값 미만이면 라벨을 null로 두고 보류합니다.

AI_CONTOUR_MODEL이 없으면 기존처럼 classification=not_trained이며 근육 등급을 만들지 않습니다. 기본 ZIP에는 실제 사진으로 학습한 모델을 포함하지 않습니다. 서버의 contour 결과도 근육량·근력 등급이라는 의미로 사용하지 않습니다.

## 5. 라벨 없는 사진의 실행·안정성 검사

```sh
.venv/bin/python scripts/evaluate_photos.py --images /절대/사진/폴더
```

사진별 실행 여부와 첫 번째·중간·마지막 사진의 재요청, 밝기 0.7/1.3, JPEG quality 50 변화량을 기록합니다. 측정 변화량과 특징 코사인 유사도는 안정성 참고 지표입니다. 정답 라벨이나 기준 측정값이 없으므로 classification_accuracy와 measurement_accuracy는 null입니다.

## 개인정보와 변경 범위

사진·잘린 영역·특징·인물 ID·라벨·학습 모델은 AI/.runtime에만 저장하며 Git에서 제외합니다. 라벨링 서버는 127.0.0.1에만 바인딩하고 외부 Host/Origin의 저장 요청을 차단합니다. 외부 공개 서비스가 아닙니다. 코드·테스트·문서는 AI/ 하위만 변경합니다. FE·BE 담당자에게 API 명세를 보내는 작업은 이번 요청에서 제외했습니다.
