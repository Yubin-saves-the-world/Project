# Qwen3 코치 시연 구현 결과

## 완료 범위

- 로컬 Ollama의 실제 `qwen3:4b`를 사용하는 한국어 대화 API 구현.
- 목표·경험·횟수·시간 설정, 질문 예시, 로딩·오류·새 대화 UI 구현.
- 일반 대화의 후속 질문 이력 전달. 과도하게 긴 이력·system 역할·제어 토큰·잘못된 수치 차단.
- 계획 요청은 서버가 시간 합계를 맞춘 일반 예시와 Qwen3 실행 팁을 분리해 제공. 20분→10분 변경 확인.
- 사진 측정값 참고는 사용자가 선택한 숫자만 전달. 사진·특징·체형 점수는 전달하지 않음.
- 측정값의 정상/이상·통증 관련 요청은 모델 응답과 구분된 안내 원칙으로 처리.
- 모델 장애·시간 초과·잘못된 응답·동시 요청을 오류로 구분. 원시 추론을 사용자에게 표시하지 않음.
- 모델 설명을 표시하지 못하는 계획 요청은 출처를 규칙 기반 예시로 표시하며 model=null. 이를 Qwen3 응답으로 위장하지 않음.
- 재실행 명령 `bash AI/run-coach.sh` 추가. 다른 환경은 Ollama와 Qwen3 모델 준비가 필요.

## 실제 확인

시연 주소: http://127.0.0.1:8023/coach

- 브라우저에서 질문 전송 → 실제 Qwen3 답변과 20분 예시 카드 표시 확인.
- 후속 질문으로 10분 변경 → 설정 10분, 단계 2+6+2분, 주 3회 유지 확인.
- 일반 후속 대화에서 이전 질문·답변을 참조한 실제 모델 응답 확인.
- HTTP 실제 연속 대화 2턴 성공. 별도 20분·10분 시간표 합계 검사 성공.
- 실제 측정 원칙 안내·잘못된 역할 및 boolean 측정값 거부 확인.
- 접근할 수 없는 로컬 모델 주소의 offline 오류 확인. 고정 답변으로 숨기지 않음.
- 같은 최종 AI 서버에서 실제 사진 분석 및 DINOv3 특징 추출도 성공.
- 응답 실측: 모델이 준비된 계획 요청 약 2.3~2.8초. 첫 로딩·일반 대화는 약 13~14초 사례가 있어 고정 속도로 보장하지 않음.
- 자동 테스트 148개 통과. 원본 FE·BE 723개 파일 일치 확인. 모든 코드·문서 변경은 AI 폴더 안.

영상 파일을 녹화한 것은 아니며, 사용자가 촬영할 수 있는 웹 시연을 준비한 상태다. 실제 실행 응답과 화면 캡처는 비공개 `.runtime/qwen3_coach_demo/`에 보관한다.

## 영상에서 구분해 설명할 것

Qwen3는 실행 팁과 일반 대화 문장을 생성한다. 시간표 예시는 규칙 기반이며, 사진 측정의 정상·이상 판정은 제공하지 않는다. 작은 모델의 사실성·개인별 운동 적합성은 검증 완료가 아니다. 일부 과도한 단정 문장을 제외하는 검사는 제한적인 패턴 검사일 뿐 안전성 보장이 아니다.

원본 Flutter 앱 코치 탭, 실제 BE 대화 이력 저장·인증과는 아직 연결되지 않았다. 원본 FE/BE 수정 제한을 지켰으며, 연결 위치와 API 계약은 `QWEN3_COACH_DEMO.md`에 제공했다. AI가 `/api/ai-coach`를 가로채거나 Anthropic 경로를 대신 바꾼 것이 아니다.

현재 로컬 작업본의 결과다. 이번 작업으로 GitHub 게시·병합이 자동 완료되지는 않았다.
