## main 반영

사용자의 지시로 PR #7을 main에 병합했습니다. 병합 커밋은 5d19a5fe9281d9f5fb881254fcc6f5811acbc7fd입니다. 변경 파일 24개가 모두 AI/ 하위인지 병합 직전에 확인했습니다. 이전 비AI PR #4·#5·#6은 병합하지 않고 닫힌 상태를 유지합니다.

기본 main.zip을 GitHub에서 실제 다운로드해 병합된 파일과 일치하는지 확인했습니다. 새 .venv를 생성하고 고정 버전 의존성을 설치했으며 공식 모델도 다운로드한 AI/.cache에 받았습니다. 과거 실험 환경의 site-packages를 사용하지 않았습니다. 다운로드한 패키지 캐시만 재사용했습니다. 해당 서버로 27장 검사와 조건 변화 검사를 수행했습니다.

## 라벨링과 학습 준비

별도 실제 라벨이 없다는 사용자 답변에 따라 로컬 라벨링 화면을 추가했습니다. 사진 27장에서 추출된 상완 43개를 개인 런타임 폴더에 준비했고 라벨은 자동 입력하지 않았습니다. 같은 인물 ID·같은 원본·같은 특징이 학습과 평가에 중복되지 않도록 검사합니다.

DINOv3 CLS+평균 패치 768차원 기반 선형 분류기를 train으로 학습하고 val로 C를 선택하며 test를 최종 평가에만 사용하는 도구를 추가했습니다. 보류 비율·분류 점수·혼동행렬을 기록하고, JSON 모델의 형식·차원·리비전을 검사한 뒤 명시적 환경 변수로만 서버에 연결합니다. 기본 API는 계속 not_trained입니다.

단위·API·인물/사진 누출 방지·이진/다중 클래스 JSON 예측 동등성·검수 저장·외부 요청 차단·모델 미지정 기본 동작 등 32개 검사를 통과했습니다. 합성 특징으로 수행한 학습 테스트는 코드 검증만 의미하며 배포용 모델이 아닙니다. 실제 데이터의 검수 0건 상태에서는 학습 명령이 명확히 거절되고 model.json을 만들지 않는 것을 확인했습니다.

## 남은 사용자 입력

http://127.0.0.1:8002에서 실제 상완을 검수하고 인물 ID·라벨·구분을 저장해야 합니다. 옷으로 가려진 영역은 제외합니다. 클래스별 인물 수와 분리 조건이 충족된 뒤에만 실제 학습·일반화 평가를 실행할 수 있습니다. 현재 사진만으로 인물 수나 클래스가 부족하면 데이터를 보충해야 합니다.

모든 코드·테스트·문서 변경은 AI/ 하위뿐입니다. 요청에서 제외한 프론트·백엔드 담당자에게 API 명세를 전달하는 작업은 하지 않았습니다.
