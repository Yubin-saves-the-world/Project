# 상완 윤곽 데이터 보충·라벨 기준 재검수

2026-11-03 작업 기록. AI 폴더만 변경했다. 사진·특징·라벨은 로컬 `.runtime`에 보관하며 GitHub에는 포함하지 않는다.

## 해결하려는 문제

최근 실험 v7의 실제 학습 라벨은 89개(weak 8, medium 46, clear 35)다. 그룹 교차검증 전체 정확도는 74/89였지만 weak는 1/8만 맞혔다. 전체 정확도만 보고 배포할 수 없다. 이미 클래스 가중치를 적용하고 있어, 같은 사진 복제나 가중치 추가만으로 새로운 사례가 생기지는 않는다. 운영 모델은 v4를 유지했다.

이 라벨은 **사진에 보이는 상완 윤곽**이다. 실제 근육량·건강 상태의 등급이나 체형 점수로 해석하지 않는다.

## 준비한 두 묶음

| 용도 | 로컬 데이터셋 | 수량 | 화면 |
|---|---|---:|---|
| 이전 등급을 숨긴 기준 재검수 | `.runtime/blind_label_audit_v1` | 9개 영역 | http://127.0.0.1:8017/ |
| 일반 운동·일상복 사진 보충 후보 | `.runtime/balance_training_batch_v1` | 37장·50개 영역 | http://127.0.0.1:8018/ |

보충 후보는 Commons 30장과 DVIDS 7장이다. 원본 전체와 최종 상완 PNG를 확인했고, 정확한 픽셀 대응·파일 해시를 검사한 뒤 공식 DINOv3 특징을 추출했다. 제외가 필요할 수 있으므로 50개 모두가 학습에 적합하다고 확정한 것은 아니다.

기존 v7 및 준비된 독립 시험 자료와 원본 SHA-256이 일치하는 사진은 없다. 이 검사는 다른 해상도·다른 사진의 동일 인물을 검증하지 않는다. 얼굴 인식은 사용하지 않았다. 저작자·촬영 시리즈·행사 단위로 **10개 보수적 분할 그룹**을 만들었으며, 10명의 독립 인물이라는 뜻은 아니다. 그룹 ID를 사진마다 바꾸지 않는다. 기존 자료에서 본 인물이 있다면 메모를 남겨 통합 전에 사람이 대응을 확인한다.

파일별 출처·저작자·라이선스·크롭 등 수정 내역은 `source-licenses.json`과 화면에 표시한다. PTPioneer 요청 출처 링크와 DVIDS 비보증 문구도 표시한다. 라이선스 기록은 초상·개인정보 권리의 포괄 승인을 뜻하지 않는다. 사진 원본은 저장소에 배포하지 않는다. 격리된 과거 인터넷 자료는 사용하지 않았다.

## 사람이 저장할 기준

1. 먼저 9개를 새로 판단한다. 이전 등급을 보여주지 않으며, 원래 라벨은 덮어쓰지 않는다. 이 묶음의 `test` 표기는 저장 구분일 뿐 모델 평가 자료가 아니다. 학습·통합 명령에서 재검수 묶음을 거부한다.
2. 이어 50개를 한 묶음으로 저장한다. 기본 그룹 ID와 `train`을 유지한다. 양팔의 등급이 달라도 관찰한 대로 입력할 수 있다.
3. **weak:** 상완이 노출되고 식별 가능하지만 윤곽 경계·음영이 거의 구분되지 않는다. **medium:** 일부 구분된다. **clear:** 명확히 구분된다.
4. 옷·가림·흐림·잘못된 크롭 때문에 판단할 수 없다면 `exclude`와 이유를 저장한다. weak 수를 맞추려고 등급을 강제로 바꾸지 않는다.

## 저장 후 진행 순서

- 재검수 일치율과 변경 항목을 확인한다. 불일치는 원본을 다시 보고 사람이 결정한다. 재검수의 새 등급을 자동 정답으로 취급하지 않는다.
- 보충 라벨의 실제 등급·그룹 분포를 집계한다. weak가 충분히 늘지 않았다면 다음 수집은 사람이 확인한 부족 조건을 중심으로 진행한다. 사진 개수보다 서로 다른 촬영·인물 그룹을 늘리는 데 집중한다.
- 원래 자료를 보존한 새 통합 버전에서 재학습한다. 그룹을 나눈 교차검증의 클래스별 재현율·macro F1·판정 수락률·수락한 결과의 정확도를 함께 비교한다. 출처별 등급 편향도 확인한다.
- 이미 확인한 독립 시험 성적에 맞춰 설정을 조정하지 않는다. 최종 성능 확인에는 인물 중복을 사람이 확인한 새 보류 묶음이 필요하다.
- 개선이 확인되기 전에는 운영 모델이나 신뢰도 기준을 자동 변경하지 않는다. 현재 데이터 부족·불균형이 해소됐다고 선언하지 않는다.

## 재검수 도구

아래 명령은 AI 폴더에서 실행한다. 출력 폴더와 보고서는 기존 파일을 덮어쓰지 않는다.

```bash
.venv/bin/python scripts/prepare_label_audit.py \
  --dataset .runtime/merged_reviewed_v7 \
  --output .runtime/blind_label_audit_NEW

.venv/bin/python scripts/label_contours.py \
  --dataset .runtime/blind_label_audit_v1 --port 8017

.venv/bin/python scripts/label_contours.py \
  --dataset .runtime/balance_training_batch_v1 --port 8018

# 9개 저장이 끝난 뒤에만 실행
.venv/bin/python scripts/score_label_audit.py \
  --dataset .runtime/blind_label_audit_v1 \
  --output .runtime/blind_label_audit_v1/consistency-report.json
```

이 보고서는 라벨 기준의 반복 일치도를 기록한다. 분류 모델 정확도나 임상적 검증 결과가 아니다. 원본 라벨 변경·재검수 미완료·항목 대응 오류·검수 이미지 변조 시 보고서 생성을 거부한다.
