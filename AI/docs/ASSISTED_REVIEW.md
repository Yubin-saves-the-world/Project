# 기존 외부 묶음 격리 안내

이 문서에 기록된 기존 인터넷 묶음과 사전검수 결과는 부적절한 이미지 혼입으로 격리했습니다. 해당 자료를 다시 열거나 학습에 사용하지 않습니다. 현재의 새 원본·상완 검수 절차는 REVIEWED_ARM_BATCH.md를 따릅니다. 아래는 과거 작업 기록입니다.

# 사진 사전검수 + 사람 최종 라벨

수집 -> 기술적 추출 검사 -> 보조자의 육안 검수 -> 사람의 상완 크롭/등급 최종 확인 순서로 진행합니다. DINOv3가 의복 가림을 자동 분류하는 모델을 새로 학습한 것은 아닙니다. 첫 육안 검수 의견은 보조자가 원본 사진을 직접 보고 작성했습니다.

현재 인터넷 사진 100장 중 기존 추출 경로를 통과한 원본 31장을 육안 검수했습니다. 사용 후보 6장, 확인 필요 7장, 제외 추천 18장입니다. 나머지 69장은 기술적 보류이며 육안 검수 완료나 상완 자체가 무조건 사용 불가능하다는 뜻이 아닙니다. 이 의견은 원본 사진 수준입니다. 최종 검수 시 추정 상완 크롭이 맞는지 확인해야 합니다.

## 표시

`training/label_server.py`는 데이터셋의 선택적 `pre_screening.json`을 읽습니다. 항목 ID별 status(candidate/needs_review/exclude_recommended), reason을 제공하고 `screening_is_ground_truth=false`를 반환합니다. 없는 데이터셋에서도 기존 라벨링은 동작합니다.

`static/labeling.html`에 사전검수 의견/이유와 필터를 추가했습니다. 기본은 사용 후보+확인 필요이며 전체, 사용 후보만, 확인 필요만, 제외 추천만으로 바꿀 수 있습니다. 의견으로 라디오나 메모를 자동 채우지 않습니다. 기존 사람이 확정한 라벨은 그대로 표시됩니다. 의견과 기존 라벨이 다르면 사람이 크롭을 확인해 수정 여부를 정합니다.

## 로컬 현재 자료

- AI/.runtime/screening_review/prescreening-100.json: 100장의 기술적 보류와 31장의 육안 검수 기록
- AI/.runtime/assisted_contour_dataset: 인터넷 두 묶음의 상완 49개, 기존 사람 라벨을 복사·보존한 별도 검수본
- 사용 후보 11영역, 확인 필요 9영역, 제외 추천 29영역
- 원본 세 묶음의 annotations.json은 수정하지 않았습니다. 앞서 확정한 묶음별 인물 ID 접두사를 유지합니다.

AI 폴더에서 `.venv/bin/python scripts/label_contours.py --dataset .runtime/assisted_contour_dataset`로 실행합니다. 현재 8002에 연결돼 있습니다. 수정한 최종 라벨은 이 별도 검수본의 annotations.json에만 저장됩니다. 후속 학습에서는 이 수정본을 명시적으로 반영해 전체 통합 자료를 다시 구성해야 합니다. 기존 통합본이나 원본 세 묶음에 변경이 자동 전파되지 않습니다.

검수 의견만으로 reviewed=true를 생성하지 않으며 학습 도구는 이 파일을 정답으로 읽지 않습니다. 사람이 이미 검수한 기록을 보존한 것과 새 의견을 자동 확정한 것은 다릅니다. 자동 검사 46개 통과, 브라우저에서 필터별 항목 수와 이유 표시를 확인했습니다.

사진 수집은 제목/카테고리 검색만으로 적합성을 보장하지 못했습니다. 다음 수집 묶음은 사용자에게 전달하기 전에 이 사전검수를 적용합니다. 데이터의 사용 가능 비율을 높이려면 수집 시 정면·단일 인물·상완 피부 노출·충분한 해상도를 우선해야 합니다. 제외된 사진을 기준 완화로 학습에 포함하지 않습니다.

모든 코드 변경은 AI/ 안에 한정합니다. 사진·사전검수 의견·원본 라벨은 .runtime 안에 보관하며 공개 저장소에 넣지 않습니다.
