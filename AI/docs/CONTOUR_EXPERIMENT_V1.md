# 첫 실제 라벨 기반 윤곽 분류 실험

사람이 검수한 92개 상완 영역 중 제외 58개를 빼고 clear 27개, medium 7개를 사용했습니다. weak는 없으므로 두 등급만 학습했습니다. 상완 윤곽의 사진상 가시성이 대상이며 근육량·근력 등급이 아닙니다.

원본 라벨과 분할은 보존했습니다. 별도 AI/.runtime/contour_experiment_v1에 인물별 60/20/20 비율의 초기 실험용 분할을 만들었습니다. prepare_contour_experiment.py는 seed 42로 미리 정한 순서를 사용하고, 학습/검증/시험의 클래스별 인물 최소 조건을 충족하는 첫 분할을 선택합니다. 특징이나 모델 평가 점수로 분할을 선택하지 않습니다. 기존 시험 데이터가 재배정될 수 있어 새로운 외부 벤치마크로 간주하지 않습니다.

- 학습: 20영역, 13인물, clear 15 / medium 5
- 모델 선택 검증: 7영역, 4인물, clear 6 / medium 1
- 최종 시험: 7영역, 5인물, clear 6 / medium 1

동결 DINOv3 768차원 특징 + 정규화 + 클래스 가중 선형 LogisticRegression을 사용했습니다. C는 검증 Macro-F1으로 선택했고 시험 데이터는 학습이나 선택에 사용하지 않았습니다.

시험 정확도 6/7(85.7%), Macro-F1 0.462입니다. 모든 시험 영역을 clear로 예측했으므로 학습 데이터의 다수 클래스만 답하는 기준(85.7%)과 같습니다. medium 재현율은 0/1입니다. medium 시험 표본도 1개뿐이어서 일반화 성능 판단이 어렵습니다. 기본 보류 임계값 0.6에서 시험 5/7만 판정했고 나머지는 보류했습니다. 이 부분 정확도만 강조해서는 안 됩니다.

실험 JSON 모델·상세 보고서·분할 계획은 .runtime/contour_experiment_v1에 저장하며 Git에서 제외합니다. 기본 서버에는 적용하지 않았습니다. 학습 후 검증된 JSON 예측기로 실제 34개 특징을 모두 읽는 것도 확인했습니다. 자동 검사 46개가 통과했습니다.
